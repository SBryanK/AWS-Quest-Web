# Presentation workflow

Use the host's presentation skill/tools for creating, editing, rendering and exporting actual PPTX or slides. This reference supplies the design and teaching decisions; it does not provide a hidden renderer or credentials. Do not claim a deck is editable or rendered without checking the delivered file.

1. Establish audience, decision/learning goal, duration, language, format and authoritative sources. Infer routine choices; ask only for consequential missing information. For an existing deck, preserve intentional branding, notes and accurate content.
2. Build a slide outline with one specific message per slide: title as claim, supporting evidence/diagram, source, and what the speaker says. Use a narrative suited to the task: problem → mechanism → evidence → options/trade-off → recommendation/action. Educational decks add mental models, worked examples, retrieval and recap.
3. Choose one visual system. Use consistent alignment and rounded grouping where useful; do not turn each slide into an app dashboard. Haptics, hover, storage controls and web navigation are not slide requirements. Start at 16:9 unless requested otherwise. Common starting ranges are 28–40pt titles, 18–24pt body and 10–12pt source notes; inspect at presentation scale and enlarge where needed.
4. Put reasoning and secondary detail in speaker notes or an appendix instead of shrinking text. Preserve units, chart baselines, interval meanings and the distinction between evidence and assumption. Use exact diagrams and editable shapes where practical. Never recreate quantitative evidence with image generation.
5. Write concise speaker notes with transitions, pronunciation/jargon help and an estimated time per slide. Label timing as an estimate and check the overall time against the brief. Use natural English–Bahasa explanations when requested, without duplicating every paragraph in two languages on the slide.
6. For assignments, map every criterion to a slide, note or appendix location. Respect the requested citation style; keep factual claims traceable to actual sources. Full AI-assisted drafting is allowed when the user authorizes it; any supplied assessment-specific restrictions still govern that assessment. Do not invent research, measurements or experiences.
7. Render every slide with the supported tool and inspect overflow, clipping, contrast, small type, image quality and reading order. Verify notes and citations separately. Recheck only affected slides after fixes. If rendering is unavailable, deliver the editable source and flag the visual check as incomplete.

Token efficiency: keep the outline compact; retrieve source sections per slide; update only impacted slides after revisions. A complete-source learning request still requires tracked reading of every requested section.
