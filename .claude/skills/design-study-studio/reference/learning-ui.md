# Study UI baseline

Use a calm reading surface, clear topic navigation, useful source links, and a separate place for recall/notes. Aim for 16–18px prose, a 60–75ch measure, visible focus, touch controls near 44px, and consistent rounded corners. Display a meaningful next action instead of a large promotional hero on every route.

Offer focus mode without removing necessary actions or stranding navigation. Preserve draft notes when toggling it. Use progressive disclosure for detailed comparisons and source notes. Search should work in the languages used, including acronyms and aliases. Do not rely on hover.

Use responsive columns that collapse at content-based breakpoints. Large mind maps stay in their own scroller and have an equivalent branch selector/list. Keep print output focused on the selected content. Optional haptics must follow feature detection, explicit opt-in, direct gestures, reduced-motion preference, and visual fallback.

Use available host/browser tooling honestly; no claims of visual verification from syntax tests. Preserve existing work unless changing it is part of the request.
