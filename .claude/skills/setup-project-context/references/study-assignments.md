# Study and assignments

For study, establish the objective (exam, conceptual understanding, implementation or presentation), baseline knowledge, deadline and realistic time. Build a prerequisite map and a plan with concrete outputs: explain a mechanism, solve a worked problem, compare alternatives and retrieve after a delay. Use English terminology with Bahasa Indonesia explanations when appropriate. Diagnose errors rather than count reading as mastery.

For an assignment:
1. Read the actual brief, rubric, submission rules and supplied source requirements. Extract a checklist with weights/word counts, deliverables, format, due date/timezone and evidence needed. Do not invent a rubric or assume a historical assignment's rules apply.
2. Map each criterion to a section, notebook, figure, slide or appendix. Capture known grading risks and unresolved questions. Use the user's authorization for full AI-assisted work; if an assessment document imposes a specific restriction, account for it explicitly.
3. Plan research, analysis, draft, verification and delivery around acceptance criteria. Build the actual authorized solution, code, calculations, figures and text; do not stop at a plan when the user requests completion.
4. Check assumptions, arithmetic, units, source provenance and the consistency of conclusions with evidence. Preserve meaningful code and reproducible analysis. Label examples/synthetic data and limitations. Never fabricate citations, study results, personal experiences or an interview.
5. Review against the rubric, word count, citation style and final file requirements. Use the host's document, spreadsheet or presentation skill for creation/rendering. Keep a concise method explanation so the user can understand and defend the work.

Maintain LEARNING.md for topics and recall; TASKS.md for deliverables; source notes for evidence; STATE.md for the immediate next action. Do not stuff the syllabus and every lesson into CLAUDE.md. An assignment and exam can share source notes while retaining separate acceptance criteria and progress.

Use design-study-studio only when building a visual learning artifact or deck. A simple conceptual question should get a direct explanation, not an unsolicited website or ten new project files.
